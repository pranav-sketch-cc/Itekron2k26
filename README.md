# I-TEKRON 2K26

Responsive React/Vite landing page for the I-TEKRON technical symposium.

## Commands

- `npm install`
- `npm run dev`
- `npm run lint`
- `npm run build`

The present application has no backend integration or required runtime environment variables. Supabase-backed authentication, registrations, passes, and organizer check-in must be implemented against the actual Supabase schema and RLS policies before they can be enabled safely.
